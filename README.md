# Telos

**Planning for what matters.**

Telos is the companion for your paper planner. Snap a photo of your weekly spread; Telos reads it, keeps a searchable digital record, and syncs to your calendar — so the small decisions on Tuesday still answer to the larger ones you set on Sunday.

## What it does

- Reads photographs of planner pages (Full Focus, Franklin, Roterunner, Monk Manual, bullet journal, and others)
- Keeps your roles, goals, and tasks in one quiet place
- Syncs calendar events to Google and Apple
- Keeps your plan on your device by default. If you sign in, it is stored privately in your own account; Google Drive sync keeps one hidden file in your own Drive. See [Privacy](privacy.html).

## Why "Telos"

*Telos* (τέλος) is Greek for the end a thing is made for. It's the word Aristotle used to ask what something is finally for. We named the app after the question.

## Running locally

```
npm install
npm start
```

Run the tests with `npm test`. Run `npm run stamp` before committing CSS or JS changes: it refreshes the pre-rendered landing page and the cache-busting version.
